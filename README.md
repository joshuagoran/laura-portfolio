# Laura Noël Landscape Design

Portfolio website for Laura Noël, a landscape designer.

## Stack

- React 19 + TypeScript
- Vite 7
- React Router DOM v7
- CSS Modules
- Biome (lint + format)

## Development

```bash
npm install
npm run dev
```

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server |
| `npm run build` | Type-check + production build |
| `npm run lint` | Lint + format check |
| `npm run format` | Auto-format |
| `npm run preview` | Preview production build |
